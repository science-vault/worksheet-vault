# Worksheet file organisation

Each resource belongs in:

`uploads/<learning-area>/<subject>/year-<number>/<strand>/<topic>/worksheets/<filename>.pdf`

Its corresponding marking key belongs in:

`uploads/<learning-area>/<subject>/year-<number>/<strand>/<topic>/answer-keys/<filename>-answers.pdf`

Use lowercase kebab-case for filenames, e.g. `word-equations-do-now.docx`. Keep the same filename stem for answer keys. Do not upload student-identifying information or confidential assessments to a public repository.

**Important:** The website's Add Worksheet form stores uploaded files in browser-local storage only. It does **not** write into these repository folders. To publish shared files, add them to the appropriate repository folders through GitHub or a future authenticated backend, then update the catalogue. GitHub Pages is static and cannot receive user uploads.

Worksheet types are intentionally not used as folders or upload filters. Classification may be added later.
